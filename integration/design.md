# V4 实装约定

使用已通过检查的 V4 画面、文字、声音和动作。开场占据主窗口的内容区，保留原生标题栏与窗口控制。中文 44–48px、英文 18–21px，瓷白 #F5F8FB、石墨 #263440、冰蓝 #77AEC1、雾银 #C2CFD8。

开场 → 原角色鞠躬 → 透明叠化 → 原生聊天界面。实装不创建预览里的模拟聊天，不更换侧栏、编辑器、项目与聊天功能。

原生界面仅挂载主题图片和配色样式；菜单、代码、弹窗保留足够实色背景。新增一个小型主题入口，用于语言、重播和恢复原界面。

2026-11-06 对话背景修正：实机截图中主内容面板几乎不透底图。当前应用的 MainContentSurface 和 WorkspaceContent::before 均使用实色底，需一起透明；左侧栏留 26% 瓷白薄层，右侧面板留 34%，顶部固定栏留 30%，输入框保留 84% 的实色及模糊。背景仍是同一张 pearl-space 图片，以 cover 铺满窗口；聊天正文不做整体透明度处理，菜单与代码块沿用实色表面。布局、字号和已批准开场保持原样。选择器取自当前应用包，并继续受现有版本校验约束。

2026-11-06 调整：沿用已批准的视觉，仅在开场右下角「跳过」左侧增加轻量「原版 / Original」文字按钮。它恢复原界面并停用主题。用户确认从任务栏启动：替换任务栏固定项，名称与官方图标保留，使用与官方程序相同的 AppUserModelID 合并窗口。维护用快捷方式仅在安装目录内；移除桌面与开始菜单新增的 Linker 入口。原有 produce 目录和官方应用注册入口保持原状。恢复按钮也将属于本启动器的任务栏快捷方式退回官方应用目标。

启动器使用官方 Store 程序与原有资料路径，私有调试管道仅由启动器持有；不开 TCP 调试端口，不改安装目录、登录资料和已有配置。当前版本核验通过才加载，版本变动时打开原版。所有自定义节点、样式、事件与音频都可释放。
