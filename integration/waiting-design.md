# 启动与同步窗口

沿用已确认的瓷白 #F5F8FB、石墨 #263440、冰蓝 #77AEC1、雾银 #C2CFD8 和原始 pearl-space 背景。Windows 原生窗口，720 × 440，居中，不增加任务栏入口。中文主状态 28px，英文 12px，阶段说明 13px；使用微软雅黑与 Segoe UI。

中轴从上到下：官方 GPT 图标 → 中文状态与英文 → 360px 细进度线 → 当前步骤。角落仅保留「本次使用原版 / Original」。不加入角色、额外卡片、日志、假百分比或新徽标。下载按已收到字节显示百分比，查询与验证使用缓慢扫描线。

普通启动先显示「正在连接」，后台并行启动应用与检查更新；已安装版本失配时显示「正在同步」，在同一个窗口里完成更新或首次兼容验证，再衔接原有开场。恢复或异常走原版，不留下等待窗口。窗口无需依赖 Codex 的 DOM 或浏览器初始化。
