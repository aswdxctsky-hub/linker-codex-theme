# 连接 · V4

已确认的独立视觉预览：双语机械音声、模拟认证、八路权限、芯片信号扩散、白龙娘鞠躬问候、主题聊天示意。

从仓库根目录运行 `python3 concept-v4/build.py`，然后打开生成的 `preview.html`。只需 Python 标准库，素材全部本地提供。

右上角切换中英音声，点击「连接」开始；提前确认会等待当前句子结束。Esc 跳过。独立预览的聊天区域是示意，不连接服务；真实接入请使用 `integration/` 的运行时主题。

`prepare_audio.py` 用于重新处理已有原始语音，需要自行提供 FFmpeg；正常播放和构建无需 FFmpeg、API Key 或生成服务。

来源和署名见 `THIRD-PARTY-NOTICES.md`。素材记录保留生成提示词、时间戳、处理方式和公共原作链接，未包含生成服务的账户下载地址及任务标识。
