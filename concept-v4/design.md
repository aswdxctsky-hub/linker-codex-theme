# 连接 · V4

保留 V3 的清透登录空间与原角色演出。每幕仍以一个中心动作组织信息，增强可感知的系统响应。

## 视觉约定

- 瓷白 #F5F8FB 为底；石墨 #263440 为中文正文；冰蓝 #77AEC1 为活动信号；雾银 #C2CFD8 为待机线路；蓝灰 #658896 为英文与次级状态。
- 中文使用微软雅黑，主状态 44–48px，次级状态 26–30px；英文 Segoe UI 18–21px，置于对应中文下方。Skyler 以完整词绘制，76px。画布为 1920×1080。
- 轴心不变，主要内容扩展到约 920px 宽。图形、文字和声音共同推进当前动作。只有权限阶段展开两侧通路。
- 音声选择常驻右上角：中 / EN，小型分段按钮。画面始终中文为主、英文为辅。

## 声音

中文沿用原始配音，重新制作更明显的机械共振、电流调制与短延迟。英文采用真实目录中的 Lowenna 女声，按相同规则处理。认证与角色的声音分开：角色问候保持柔和。每阶段以实际音频长度决定最短停留时间，切换语言不会叠音。

## 对照与取舍

避免把双语排版变成双倍的信息负担：英文只解释同一条状态，不增添重复说明。权限以八条细线构成一个整体，不做八张卡片。其余阶段增加短响应、刻度和几何定位，保留大面积留白。主题背景、GPT 标志与原有角色动画继续使用。

独立 Windows 离线预览；模拟认证不采集身份数据，能力名称用于演出，不代表真实服务权限。没有宿主安装或应用配置更改。
